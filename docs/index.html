Metodologia & Transparência

O Radar Científico Brasil é um observatório em implantação. Os coletores visitam páginas institucionais cadastradas; cobertura integral das agências não é presumida.

Origem dos dados

Links e títulos derivados de fontes institucionais. O endereço original de cada oportunidade é preservado. Nem toda chamada detectada possui prazo, valor ou número de vagas disponível.

Interpretação estatística

Um edital não equivale a uma bolsa, vaga, projeto ou valor concedido. Período de detecção não é necessariamente a data oficial de publicação. Ausência de valor não é zero.

Status de oportunidades

“Listada como aberta na fonte” significa exclusivamente que o coletor encontrou a chamada em página que se apresenta como lista de oportunidades abertas; a validade deve ser confirmada no edital.
